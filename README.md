# Excel Pivot Table Practice

## What I Built
5 sales analytics reports using Excel Data Model and Pivot Tables.

## Reports
1. Top 10 Products by Net Sales
2. Category-wise Sales (2022 vs 2023)
3. Top 5 & Bottom 5 Customers by Quantity
4. New Products in 2023
5. Top 5 Region by Net Sales
